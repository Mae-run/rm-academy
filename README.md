# RM 兵工厂 · 学员训练站

[![GitHub stars](https://img.shields.io/github/stars/Mae-run/rm-academy?style=social)](https://github.com/Mae-run/rm-academy)

> 我是**视觉组的小登** 🐣，这个项目是我一边学一边攒出来的。
> 现在把它发出来，主要是想表明「**正在做**」这件事——离完善还差得远，很多地方我自己也知道不够好。
> **欢迎大家多提建议、多拍砖**，我会一直改下去。

一套面向 RoboMaster 机器人战队的**离线学员训练站**：10 门课 + 1379 道手写题 + 14 个开源项目精读案例，纯静态、可离线使用，数据保存在本机浏览器。

**主题风格**：明日方舟 · 终末地（战术科幻 / 黑夜 + 白天双主题）

---

## 快速开始

**方式一：浏览器直接打开（最简单）**

用浏览器打开 `index.html` 即可。进度数据存在本机 localStorage，可导出备份、换机不丢。

**方式二：便携版 exe（可选）**

`release/RM兵工厂-Portable.exe` 双击即用，免安装、免联网。该 exe 体积较大，未随仓库提交，需自行构建或从 Release 页获取。

## 功能

- 📚 10 门课系统化学习，章节可勾选进度
- ✍️ 1379 道手写题（含精选 + 随堂测），答案可展开查看
- 🎯 14 个高质量 RM 开源项目精读案例（视觉 7 + 电控 4 + 合集 2）
- 📕 错题本（随堂测自动收录 + 手写题手动收录）
- 🔥 14 天连续打卡 + 今日练会计数
- 📝 随堂测战绩面板（正确率 + 进度条）
- 💾 数据备份与恢复（导出 .json，换机不丢）
