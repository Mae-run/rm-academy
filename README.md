# RM 兵工厂 · 学员训练站

一套面向 RoboMaster 机器人战队的**离线学员训练站**。10 门课 + 1379 道手写题 + 14 个开源项目分析案例 + 错题本/打卡/数据备份，全部本地运行，不联网。

**主题风格**：明日方舟·终末地（战术科幻 / 黑夜+白天双主题）

---

## 快速开始

**方式一：便携版 exe（推荐）**

下载 `release/RM兵工厂-Portable.exe`，双击即用。无需安装，无需联网。

**方式二：浏览器直接开**

用浏览器打开 `index.html`。数据存在本机浏览器 localStorage，进度可导出备份。

## 功能

- 📚 10 门课系统化学习，章节可勾选进度
- ✍️ 1379 道手写题（含精选 + 随堂测），答案可展开查看
- 🎯 14 个高质量 RM 开源项目精读案例（视觉 7 + 电控 4 + 合集 2）
- 📕 错题本（随堂测自动收录 + 手写题手动收录）
- 🔥 14 天连续打卡 + 今日练会计数
- 📝 随堂测战绩面板（正确率 + 进度条）
- 💾 数据备份与恢复（导出 .json，换机不丢）
