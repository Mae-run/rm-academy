    📕 错题本怎么用？

    自动：随堂测答错立刻进错题本。手动：手写题没过关，题卡上点「加入错题本」。 顶栏「错题」按钮随时打开，红数字 = 未消灭数。看解析 → 搞懂 → 点「已消灭」。错题是第二本教材，别怕攒，怕的是不看。

    🔥 连续打卡怎么算？

    每天标记任意一题「已练会」= 当天打卡。练习中心顶部有 14 天打卡日历，橙色 = 有练题。 今天还没练不会打断昨天的连续记录（天数从昨天接着算），但你想涨天数就得今天练。

    💾 数据怎么备份？换电脑怎么迁移？

    顶栏「数据」→「导出备份文件」生成 .json。新电脑上打开应用 →「数据」→「从备份恢复」→ 选中文件。 包含全部进度、错题本、测验战绩。建议每周导出一次。

    📝 随堂测战绩在哪看？

    练习中心顶部「随堂测战绩」面板：累计答题、正确率进度条。哪门课概念虚，一眼看穿。

二、安装与启动

下载：拿到 RM兵工厂.exe（或文件夹版 zip），放到任意目录。建议放在桌面或 D 盘，路径别带太多层。
启动：双击 RM兵工厂.exe。首次启动要 2~5 秒加载题库，看到 🦐 图标和「RM 兵工厂」首页即成功。
桌面快捷方式：右键 exe →「发送到」→「桌面快捷方式」，以后一键开。
卸载：直接删文件夹即可，不写注册表。学习进度存在 %APPDATA%\RM兵工厂（或用户数据目录），删掉即彻底清干净。

三、怎么学（课程篇）

  • 按顺序走：首页有师父排的 25 周学习路线，C → C++ → Python → Linux → ROS 2 → 电控/视觉双线。别跳，前面的章节是后面的地基。
  • 左侧目录：每门课左侧是章节目录，点章节名跳转。章节标题旁的方框 ☐ 点一下 = 标记这章学完，目录里会打勾划线。
  • 代码必须手敲：教程里的代码块右上角有「复制」按钮——那是给你对照用的，不是让你粘贴的。先自己敲，卡住了再看。
  • 随堂测：章节里的选择题，点了立刻出对错和解析。答错不扣分，但要搞懂为什么错。
  • 昼夜主题：右上角 ☀️/🌙 按钮切换深色/浅色主题，眼睛舒服才学得久。

四、怎么练（练习篇）

流程：看题 → 纸上/IDE 里自己写 → 点「我写完了，看参考」对答案 → 差距大的话第二天重写一遍 → 点「标记已练会」。
精选好题 ★：练习中心打开时，顶部就是「师父精选好题」区，带金色高亮和 ★ 标。一个模块 15+ 道，时间紧就先刷这批。也可以用筛选器「只看精选」。
筛选与搜索：顶部工具栏可以按语言、难度（入门/进阶/实战）筛选，支持关键词搜索。列表太长会自动分页加载，往下滚就好。
随机抽题 🎲：点击「随机抽题」，从 1379 题里随机抽一道并自动滚过去。适合每天的热身。
打印卷子 🖨：筛选出想练的题（比如「C 语言 + 入门」），点「打印卷子」，浏览器打印成纸质卷。师父说过：纸上写出来的才是真功夫。

五、进度与数据

  • 进度存在哪：全部存在本机，不上传、不联网。清浏览器数据 / 重装系统前想保留进度，用「导出进度」功能（首页右上角菜单）。
  • 统计面板：练习中心顶部五个数字——总题数、已练会、完成度、精选已练、今日练会。「今日练会」是你每天的打卡数，别让它归零。
  • 练会标准：不是「看懂了」就算，是不看答案能写出参考答案水平的代码。自欺欺人的勾不如不打。

七、常见问题

Q1：双击 exe 没反应 / 被 Windows 拦截？
SmartScreen 会拦未签名的程序。点「更多信息」→「仍要运行」。若杀毒软件误报，加白名单即可——本程序纯本地静态站，不联网不收集任何数据。
Q2：进度丢了？
检查是不是换了浏览器或清了浏览器数据（网页版）。桌面版进度存在固定目录，除非手动删，否则不会丢。养成用导出备份的习惯。
Q3：能联网用吗？手机能开吗？
全站离线可用，不需要网络。网页版（双击 index.html）在手机浏览器也能开，但推荐大屏练题。
Q4：随机抽题抽到学过的怎么办？
再点一次就是了。重复抽到旧题不亏——复练本身就是记忆曲线的一部分。
Q5：打印出来的卷子没带答案？
打印样式默认隐藏答案区，只出题面。需要答案版：先展开答案再打印。
