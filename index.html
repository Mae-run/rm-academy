总学习路线（师父排的兵期）
按周推进，每周 10~14 小时。卡住超过两天，就回来重新看路线——不是你笨，是顺序错了。
第 1~4 周

C 语言补课（指针重火力）

你已会基础语法，直接从指针开火：指针基础 → 二级指针 → 指针与数组/函数 → 内存模型 → 结构体传参 → 文件与调试。每天手写 2~3 道指针题。

指针四则运算指针与数组等价性malloc/free函数指针结构体内存对齐
第 5~8 周

C++（C 的超集，先学增量）

只学 C 没有的：引用、函数重载、默认参数、string/vector、类与 RAII、智能指针、模板、lambda、STL 算法、多线程。全程和 C 对照。

引用 vs 指针vector vs 数组RAIIunique_ptrlambda
第 9~11 周

Python（一周上手，两周熟练）

用 C 的脑子学 Python：类型是贴在值上的标签、列表是动态数组、字典是哈希表、切片是指针算术的糖。重点练 NumPy 向量化思维。

列表推导式字典NumPy 广播matplotlib 画图

命令行生存 → 文本三剑客 → Shell 脚本 → git 版本控制 → cmake 构建 → gdb 调试 → ssh 部署 → 交叉编译 + systemd 守护。和 ROS 2 同步穿插着学。

铁律（师父的三条规矩）
  • 代码必须手敲。复制粘贴学不会编程，就像看别人健身练不出肌肉。教程里的每段代码都要自己敲一遍、跑一遍、改错一遍。
  • 练习必须手写。每章配手写题（纸上写或白板写），写完对照参考答案。手写强迫你想清楚每一个分号和边界。
  • 错题必须复盘。用练习中心的自评标记，练会的打勾，没练会的第二天重写。写不出参考答案水平的代码，就不算练会。
师父的话

嵌入式和机器视觉这行，靠的不是天赋，是手上的肌肉记忆和脑子里的内存模型。你现在觉得指针难，是因为你还没把它画在纸上；你觉得 EKF 难，是因为你还没把它一行行推过。这站上的每一道题，都是我十年里踩过的坑。把它们练完，你就能独当一面了。
